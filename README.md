# Flood-Prediction-
Developed a Flood Prediction System using Python, Pandas, NumPy, and Scikit-learn. Combined rainfall data from Bangladesh and Punjab, performed data preprocessing and feature engineering, and trained a Random Forest model achieving ~97% accuracy. Built a Streamlit interface with MongoDB for prediction storage.

🌊 Flood Prediction System

A machine learning-based flood prediction system that uses historical rainfall data from Bangladesh and Punjab to predict flood occurrence. The project includes data preprocessing, feature engineering, and a Random Forest model achieving ~97% accuracy. A Streamlit web interface and MongoDB integration are included for interactive predictions and data storage.
